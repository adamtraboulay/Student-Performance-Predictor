# Student-Performance-Predictor
A machine that accurately predicts the perfomance of a student's final grade based upon imformation such as 
time spent studying, previous grades and amount of absences.

## Data

Uses the UCI [Student Performance Data Set](https://archive.ics.uci.edu/dataset/320/student+performance)
(`data/student_data.csv`), 395 students with demographic, family, and study-habit features plus
three grade periods (G1, G2, G3).

## Project structure

- `notebooks/eda.ipynb` - exploratory data analysis (distributions, pivot tables, missing/duplicate checks)
- `src/preprocess.py` - loads the CSV and encodes categorical features
- `src/train.py` - trains and compares a linear regression and a random forest, saves the best model to `models/`
- `app.py` - Streamlit app for entering a student's info and getting a predicted final grade
- `models/` - trained model + feature column list (generated by `train.py`)

## Usage

```bash
pip install -r requirements.txt
python3 src/train.py
streamlit run app.py
```
